## 🎯 Kenapa Saya Buat Ini?

Sebagai developer yang sering bekerja dengan Discord bot, saya butuh tools yang simpel untuk:
- Test webhook dengan cepat
- Simpan multiple webhook config
- Bisa dipakai di HP saat mobile
- No login required, no backend needed

Jadilah website ini! ✨

## 🚀 Fitur Unggulan

### 🎨 **Interface Keren**
- ✅ **Tema Discord** - Warna khas Discord (#5865F2)
- ✅ **Dark mode** - Mata gak sakit walau pakai lama
- ✅ **Responsif** - Desktop & mobile friendly
- ✅ **Animasi halus** - Transisi yang smooth

### 🔧 **Fitur Teknis**
- ✅ **Multi-webhook** - Simpan banyak webhook sekaligus
- ✅ **Embed support** - Kirim pesan dengan embed yang cantik
- ✅ **Custom bot identity** - Ganti nama & avatar bot
- ✅ **Test mode** - Test tanpa benar-benar kirim ke Discord
- ✅ **Auto-save** - Data tersimpan di browser Anda
- ✅ **Log history** - Riwayat pengiriman lengkap

### 📱 **Optimasi Mobile**
- ✅ **Bottom navigation** - Gampang dijangkau jempol
- ✅ **Big buttons** - Tombol gede biar gak miss-click
- ✅ **Hamburger menu** - Menu lengkap di satu tempat
- ✅ **Touch-friendly** - Form yang mudah diisi di HP

## 🛠️ Teknologi yang Dipakai

**Frontend Stack:**
- HTML5 + CSS3 (vanilla, no framework)
- JavaScript ES6+ (pure, no libraries)
- Font Awesome 6 (icons)
- Google Fonts (Poppins & Roboto Mono)

**Storage:**
- LocalStorage (simpan data di browser)
- No database needed!

**API:**
- Discord Webhook API
- Fetch API untuk HTTP requests
